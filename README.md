# Active Fitness Gym

A responsive single-page website concept for Active Fitness Gym in Surat, built with React, TypeScript, and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The current site is a presentation demo. Trainer profiles, testimonials, and some business details need client confirmation. Contact and membership forms are front-end demos and do not send submissions to a lead system.
